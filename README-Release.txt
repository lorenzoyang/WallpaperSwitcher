===========================================
                 使用说明（中文）
===========================================

感谢您下载 Wallpaper Switcher！

本压缩包包含完整程序，请按照以下步骤使用：

✅ 使用步骤：

1. 解压缩此文件至任意位置，例如：C:\Programs\WallpaperSwitcher
2. 进入解压后的 bin 文件夹
3. 双击运行 WallpaperSwitcher.exe 即可启动程序

⚠️ 注意事项：

- 请不要移动或删除 bin 文件夹中的任何文件
- WallpaperSwitcher.exe 必须保留在 bin 文件夹内才能正常运行
- 若要创建快捷方式，右键 WallpaperSwitcher.exe → “创建快捷方式”，然后将其放置在桌面或固定到开始菜单

🧠 小贴士：

- 第一次启动可能略慢（加载配置）
- 关闭主窗口不会退出程序，而是最小化到系统托盘
- 右键托盘图标可快速切换壁纸、设置等
- 设置界面支持修改全局快捷键与开机启动等选项

如需更多说明或帮助，请访问项目主页：
https://github.com/lorenzoyang/WallpaperSwitcher

===========================================
                 Instructions (English)
===========================================

Thank you for downloading Wallpaper Switcher!

This ZIP file contains the full package. Follow the steps below to use it:

✅ Steps:

1. Extract the ZIP file to any folder, e.g., C:\Programs\WallpaperSwitcher
2. Open the extracted folder and navigate to the bin directory
3. Double-click WallpaperSwitcher.exe to launch the app

⚠️ Important Notes:

- Do NOT move or delete any files inside the bin folder
- WallpaperSwitcher.exe must remain inside the bin folder to function properly
- To create a shortcut, right-click WallpaperSwitcher.exe → "Create shortcut", then move it to your Desktop or Pin to Start

🧠 Tips:

- First launch may be slightly slower (initial setup)
- Closing the main window will minimize the app to the system tray
- Right-click the tray icon for quick actions: switch wallpaper, change folders, open settings, or exit
- Use the Settings window to customize hotkeys, enable auto-start, and more

For detailed instructions or support, visit the project homepage:
https://github.com/lorenzoyang/WallpaperSwitcher
