===========================================
                 使用说明（中文）
===========================================

感谢您下载 Wallpaper Switcher！

本压缩包包含完整程序。Wallpaper Switcher 是便携版软件，不需要安装。

使用步骤：

1. 解压缩此文件至任意位置，例如 C:\Programs\WallpaperSwitcher
2. 进入解压后的 bin 文件夹
3. 双击运行 WallpaperSwitcher.exe

重要说明：

- 请不要移动或删除 bin 文件夹中的任何文件
- WallpaperSwitcher.exe 必须保留在 bin 文件夹内才能正常运行
- 如需创建快捷方式，右键 WallpaperSwitcher.exe，选择“创建快捷方式”，然后放到桌面或固定到开始菜单

使用提示：

- 第一次启动可能略慢
- 关闭主窗口不会退出程序，而是最小化到系统托盘
- 如需完全退出，请右键托盘图标并选择“退出”
- 右键托盘图标可快速切换壁纸、切换文件夹、打开设置或退出程序
- 设置界面支持修改全局快捷键、切换模式和开机自启
- 用户设置和快捷键保存在固定目录：C:\Users\<用户名>\AppData\Local\WallpaperSwitcher
- 后续更新时，完全退出程序后替换新的 WallpaperSwitcher.exe 或完整包文件即可保留数据
- 如需删除程序，请先从托盘退出，再删除 exe 或解压目录；如果不想保留设置，再删除上述用户数据目录

多屏幕限制：

- 当前版本不提供一致的多屏幕支持
- 原生模式下，切换下一张壁纸时可能只会切换其中一个屏幕的壁纸
- 自定义模式下，切换时通常会把同一张下一张壁纸同步设置到多个屏幕
- 当前版本不支持按屏幕单独选择壁纸

如需更多说明或帮助，请访问项目主页：
https://github.com/lorenzoyang/WallpaperSwitcher

===========================================
                 Instructions (English)
===========================================

Thank you for downloading Wallpaper Switcher!

This ZIP file contains the full portable package. No traditional installation is required.

Steps:

1. Extract the ZIP file to any folder, for example C:\Programs\WallpaperSwitcher
2. Open the extracted folder and go to the bin directory
3. Double-click WallpaperSwitcher.exe

Important notes:

- Do not move or delete any files inside the bin folder
- WallpaperSwitcher.exe must remain inside the bin folder to work correctly
- To create a shortcut, right-click WallpaperSwitcher.exe, choose "Create shortcut", then move it to your Desktop or pin it to Start

Tips:

- First launch may be slightly slower
- Closing the main window minimizes the app to the system tray instead of exiting
- To exit completely, right-click the tray icon and choose "Exit"
- Right-click the tray icon to switch wallpapers, change folders, open Settings, or exit
- Use Settings to customize global hotkeys, switching mode, and startup launch
- User settings and hotkeys are stored in: C:\Users\<YourUsername>\AppData\Local\WallpaperSwitcher
- To update later, fully exit the app and replace WallpaperSwitcher.exe or the full package files; your data will be kept
- To remove the app, exit it from the tray and delete the exe or extracted folder; delete the user data folder only if you do not want to keep settings

Multi-monitor limitation:

- The current version does not provide consistent multi-monitor support
- In Native Mode, Next Wallpaper may change the wallpaper on only one monitor
- In Custom Mode, switching usually applies the same next wallpaper across monitors
- Per-monitor wallpaper selection is not supported

For detailed instructions or support, visit the project homepage:
https://github.com/lorenzoyang/WallpaperSwitcher
